Monthly Updates [January]

January 2026 updates • Jan 1
nbats

INFO

These update threads only contain major updates. If you're interested in seeing all minor changes you can follow our Commits Page on GitHub or Updates Channel in Discord.

Wiki Updates ​

  • Added Alternative Frontend of FMHY with a totally different design. This pulls from the official source, so it will stay synced with new edits. It also has a random site / 2 button that works per page. Note the front page for this has been removed, and it now directs to the wiki itself. Thank you to nw for making this.

  • Added 3 New Instances to our Backups Page (Samidy, JBugel, ArtistGrid).

  • Added Catppuccin / 2 as an option in our color picker. Thank you to Samidy for doing this.

  • Added a new section for Textbooks.

  • Added a new section for File Info / Metadata.

  • Merged Linux + Mac Torrent Clients into the Main Section, and added labels + platform icons. Before vs. After / 2

  • Re-ordered Light Novel Sites based on library size and UI, added labels, removed small libraries, and starred two that stood out (NovelCool + WuxiaClick). Before vs. After / 2

  • Debloated the Audio Recommendation section + added a new section for Song / Artist Discovery. Before vs. After / 2

  • Added Labels to both Linux Cheat Sheets + Linux Distros. Thank you to helxop. Before vs. After / 2

  • Revamped our Feedback Window / 2 to try to improve its look. Thank you to Samidy for doing this.

  • Added a backup / frontend for our Grading Page, and moved both our Backup + FAQ pages to our website instead of Reddit/GitHub. Thank you to Roi Goat + Samidy for doing this.

  • Improved our theme handler, which will help us more easily switch or add themes in the future (like Halloween, Christmas, etc.). Thank you to Land for doing this.

  • Added 360 Total Security to unsafe sites. If you install any of their apps, it will keep giving the user popups to install their "toolbox," or will install it without consent if you use clean, repair, or optimize options. Once installed, the toolbox will then modify your default apps (such as your browser) and switch them all to 360 options.

Stars Added ⭐ ​

  • Starred DDLBase in Video Download. Has both 4K + 1080p content, uses only fast hosts, and has a huge library.

  • Starred Anime Realms in Anime Streaming. Good sources, nice UI, auto-next, custom player, and multi-language support.

  • Starred Music Hunters in Telegram Audio Bots. Supports lots of sites, has good quality, and is easy to use.

  • Starred AstralGames in Game Downloading. Big library, fast hosts, pre-installs, and allows requests.

  • Starred Comix in Manga Sites. Big library, allows uploads, nice UI, and will be adding more languages soon.

  • Starred Monochrome in Audio Streaming. No sign-up needed, multi-API integrations, Last.fm integration, customizable, and a big library.

  • Starred Rive, Aether, Willow, and FlyX in Streaming. These have nice custom players, lots of features, fast streams, and impressive UIs.

  • Starred StreamSports99 in Live Sports. Has fast servers and a solid UI.

  • Starred Control Panel for Twitter in Twitter/X Customization. Adds a lot of extra features, lets you hide sections you don't use, improves UI, and much more.

  • Starred Rootz in File Hosts. Good speed, 25GB per file, and lasts 15 days after the last download.

  • Starred PigenAI in Image Gen. Has unlimited Imagen 4, Qwen, and Nano Banana.

  • Starred Nuvio in iOS Streaming. This uses Stremio plugins and has fewer limits than the "Lite" version currently available on iOS.

  • Starred Flud in Android Torrenting. Allows binding, is well-maintained, and ads can easily be blocked via DNS.

  • Starred Sleeping Guide in Physical Health. A sleep hygiene/science guide; seems to be well-received so far, curated by Dan.

  • Starred OpenMW in Remakes / Recreations. Complete ground-up reimplementation of Morrowind, approved by Bethesda themselves.

  • Starred Clone Hero in Remakes / Recreations. Feature-rich Guitar Hero clone, thousands of songs + playlists, no lag, works with all guitar controllers, and supports MIDI drum kits.

  • Starred Gidd in Multiplayer Browser Games. Has quality versions of things like Monopoly, GeoGuessr, card games, etc.

  • Starred QEMU in Virtual Machines. Performs well on non-Windows systems; best used with Virt-Manager or Vagrantup.

  • Starred Restic in File Backup. Easy to use, multi-platform, and performed well in benchmarks.

  • Starred Gemini CLI in Coding AIs. This seems to have some of the best limits as of now.

Things Removed ​

  • Removed CrocDB as they've been hit by DMCA / 2.

  • Removed the IcebergCharts website as they've been hacked a few times now / 2, and can't figure out why it's happening. We may re-add it in the future if they figure it out. Note that we'll keep the subreddit in its place for now.

  • Removed CanvasBlocker as it's Firefox-only, and FF has this built-in now; it can also apparently make fingerprinting worse in some cases and isn't maintained well anymore.

  • Removed FTV and WAC from Live Sports as both are now gone.

  • Removed Foxified as it's suddenly filling results with ads / 2.

  • Unstarred OnTheSpot as it will be losing Spotify support soon.

  • Unstarred Windsurf in Coding AIs as its limits and free models aren't as good anymore.
